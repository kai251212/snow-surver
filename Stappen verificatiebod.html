Verificatie met Wick Bot

Voltooi de onderstaande stappen om volledige toegang te krijgen tot de Apex Arena E-sport server.

1
Start de Verificatie Ga naar het kanaal #verify-here en klik op de grote groene knop met de tekst "Verify".
2
De Groene Code (CAPTCHA) Er verschijnt een afbeelding met een groene code bestaande uit cijfers en letters. Bekijk deze goed.
3
Code Invoeren Typ de code exact over in de chatbox of het invulvenster. Let op: de code is hoofdlettergevoelig!
4
Toegang Verleend Zodra de bot de code accepteert, worden je rollen automatisch toegewezen en zie je alle kanalen.
Lukt het niet?
Mocht de code onleesbaar zijn of krijg je een foutmelding, klik dan op de "Redo" of "Help" knop voor een nieuwe poging.
